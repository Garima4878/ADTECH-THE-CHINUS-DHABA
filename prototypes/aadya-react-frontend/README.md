# React frontend prototype (Aadya)

Early React/Vite prototype of the customer site: landing page, QR table entry and menu cards
(`src/Home.jsx`, `src/TableEntry.jsx`, `src/MenuCard.jsx`, `src/menuData.js`).

It is kept here for reference. The live customer website is `index.html` / `app.js` / `styles.css`
in the repository root, and the backend uses the root `src/` folder. These files used to sit in that
folder too and were moved here so the two aren't mixed up. There is no `package.json` for this
prototype, so it doesn't build on its own.
